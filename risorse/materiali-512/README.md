# Materiali per interni

Una selezione di texture PBR da [ambientCG](https://ambientcg.com/), pronta per essere usata in una futura personalizzazione. L'app non applica o carica queste immagini automaticamente. La cartella è separata dai file pubblici dell'app e non entra nella build finché non viene integrata.

| Materiale | Possibile uso | Fonte |
| --- | --- | --- |
| WoodFloor051 | Pavimento in legno | [WoodFloor051](https://ambientcg.com/a/WoodFloor051) |
| Fabric018 | Tessuti | [Fabric018](https://ambientcg.com/a/Fabric018) |
| Plaster001 | Intonaco e pareti | [Plaster001](https://ambientcg.com/a/Plaster001) |
| Tiles074 | Piastrelle | [Tiles074](https://ambientcg.com/a/Tiles074) |

Ogni archivio ZIP contiene tre immagini JPG ridimensionate a 512 × 512 pixel dagli originali 1K: `Color` per il colore, `NormalGL` per il rilievo apparente e `Roughness` per la ruvidità. Estrai l'archivio del materiale scelto. Per usarlo con Three.js occorre modificare il codice: carica le immagini desiderate, imposta la mappa colore in spazio sRGB e associa le altre mappe a un materiale compatibile, regolando scala e ripetizione. Per maggiore dettaglio, scarica gli originali dai link sopra.
